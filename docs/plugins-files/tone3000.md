# Getting Tones from TONE3000

!!! info "New in 1.14"
    TONE3000 inside the Web UI is new in MOD OS 1.14.

[TONE3000](https://www.tone3000.com) is a large online library of NAM models and impulse responses (IRs) of real gear, shared by musicians. From 1.14 you can browse it from inside a plugin and download a tone straight to the Dwarf: no separate download, no file copying.

Brought to you by MOD Audio, made possible by our friends at Starless.

## What you need

- A free TONE3000 account.
- Internet on the computer running the Web UI. The computer downloads the tone and copies it to the Dwarf, so the Dwarf itself does not need to be online.

## Which plugins

**Browse tones** appears in the file list of plugins that load:

| Plugin type | What you can browse | Saved in |
|---|---|---|
| NAM loaders | NAM models (all sizes, including A2) | **NAM Models** |
| Cabinet simulators and cab loaders | Cabinet IRs | **Speaker Cabinets IRs** |
| IR loaders (reverbs, spaces) | IRs | **Reverb IRs** |

AIDA-X loaders do not get it: TONE3000 has no AIDA-X models.

## Getting a tone

1. Open the plugin's settings window and open its file list.
2. Click **Browse tones** (it has the TONE3000 logo).
3. If you are not logged in to TONE3000, a welcome window explains the integration. Click **Continue**, then log in in the window that opens. You log in on the TONE3000 site, not in the Web UI.
4. Browse the catalogue and choose a tone. You can preview tones before you pick one.
5. The tone is copied to the Dwarf, the window closes, and the plugin's file list is refreshed. Pick the new file in the list.

## Where the files go

- A tone with **one model** is saved as one file, named after the tone.
- A tone with **several models** gets its own folder, named after the tone, with one file per model. See [Loading Files into Plugins](plugin-files.md) for moving through folders.
- Nothing is overwritten: if a file or folder with the same name exists, a number is added (`VOX AC 30 01`, `VOX AC 30 02`, …).

The downloaded files are ordinary user files: you can rename, move or delete them in the File Manager.
