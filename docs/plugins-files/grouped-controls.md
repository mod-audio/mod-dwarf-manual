# Grouped Plugin Controls

!!! info "New in 1.14"
    Earlier releases showed all of a plugin's controls in one block.

Plugins with many controls can sort them into groups, for example one group per band of an equalizer, or one per section of an amp. In the plugin's settings window, the controls of a group sit together and share a colour, so you can see at a glance which knobs and switches belong together.

The plugin decides the groups. A plugin that does not declare any shows its controls as before.

Nothing else changes: the controls work, save and can be assigned exactly as before (see [Assigning Controls](../first-pedalboard/assigning-controls.md)).
