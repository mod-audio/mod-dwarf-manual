# Easy Spin Programs

!!! info "New in 1.14"
    The Easy Spin Programs folder is new in MOD OS 1.14.

Audiofab's Easy Spin plugin loads **programs**: small `.json` files. From 1.14 the Dwarf has a folder for them, and the plugin lists the programs in it.

1. In the Web UI, open the File Manager. Under **Plugin Resources** you will find **Easy Spin Programs**.
2. Upload your `.json` program files there.
3. In the Easy Spin plugin's settings window, pick a program from its file list (see [Loading Files into Plugins](plugin-files.md)).

Install the Easy Spin plugin from the Plugin Store.
