# Loading Files into Plugins

!!! info "New in 1.14"
    The file list in a plugin's settings shows your folders. On earlier releases, every file was in one flat list.

Some plugins load a file: a NAM model, a cabinet or reverb IR, an audio loop, an SFZ instrument and so on. You pick the file in the plugin's settings window, from a list of what is in the matching folder of your user files.

## What the list shows

1. **Folders**, with a folder icon.
2. **Your files** in the current folder.
3. The plugin's own **default file**, if it has one.
4. **Browse tones**, on NAM, cabinet and IR loaders: see [Getting Tones from TONE3000](tone3000.md).

## Moving through folders

| Do this | What happens |
|---|---|
| Click a folder | You go into it: the list shows what is inside |
| Click the open folder at the top of the list (marked with an up arrow) | You go back up one level |
| Click a file | The plugin loads it |

Folders can be as deep as you like.

## Where the folders come from

Every folder you create in the matching user-files folder shows up here, for example inside **NAM Models** or **Speaker Cabinets IRs**. You can create, rename and move them in the File Manager (in the Web UI menu). Tones downloaded from TONE3000 with more than one model get a folder of their own.
